Use the data

Every executive order and proclamation Theodore Roosevelt signed as president is available as open JSON: date, number, title, summary, subjects, places, countersignature, citations and text. Build a classroom timeline, a map of national forests, or a daily post. No key, no sign-up.

Embedding on a web page? See the widgets: one script tag, four ready-made cards.

JSON API

Base URL: https://executiveactions.labs.trlibrary.com/api/v1/. Every endpoint is a static file, cached at the edge and open to cross-site requests.

EndpointReturns
index.jsonDataset metadata, counts by type, year, month and subject, sources, license and the endpoint list
documents.jsonEvery document in compact form: id, type, number, date, title, summary, categories, action, states, significance, stories, has_text. Lord's duplicate entries come last, marked duplicate_of
documents/{id}.jsonOne full record: text and its provenance, citations, countersignature, places, people, date and title notes, what happened next (reception, impact, legacy, where it stands today), connected documents, story titles, previous and next by date
years/{YYYY}.jsonDocuments signed in a year (1901–1909)
categories/index.json, categories/{slug}.jsonSubjects with counts, and the documents in each
states/index.json, states/{slug}.jsonStates and territories with counts, and the documents acting on each
types/{type}.jsonexecutive_order, proclamation or unnumbered_order
stories/index.json, stories/{number or slug}.jsonThe stories behind the documents: metadata, Markdown, rendered HTML, open questions and the documents each covers
on-this-day/{MM-DD}.jsonDocuments signed on that calendar date in any year, most significant first. Every date has a file, even when it is empty
then-and-now/index.jsonPresent-day parks, forests, refuges and other places that trace to a Roosevelt document, with how they are linked. Also then-and-now/{kind}.json
countersigners.jsonWho countersigned the proclamations, in what role, how often and when
search.jsonid, title, summary, date and type for client-side search

Any path from the table above, relative to /api/v1/.

…
fetch("https://executiveactions.labs.trlibrary.com/api/v1/on-this-day/06-08.json")
  .then(r => r.json())
  .then(d => d.documents.forEach(x => console.log(x.date, x.label, x.title)));

Fields worth knowing

  • id: eo-1003, eo-389-a, eo-288-half for numbered executive orders; proc-563 for proclamations; proc-x-1907-01-24 for the three proclamations outside the numbered series; uo-001 to uo-126 for Lord's unnumbered orders.
  • date: YYYY-MM-DD, or YYYY-MM when only the month is known (date_precision: "month"), or null.
  • text.kind: statutes_digitization, wikisource_transcription or collated. text.verified is false until the text has been checked against the printed page. Check the citations.statutes.page_image before quoting.
  • duplicate_of: set on the 21 entries in Lord's list that describe an order already in the numbered series. Treat them as cross-references, not separate actions.
  • significance: 1 (individual personnel action) to 5 (landmark), assigned by the Library as a browsing aid. summary, categories and significance may be null or empty while work continues; fall back to title.

Downloads

  • documents.csv, one row per document, for spreadsheets
  • documents.jsonl, the full dataset with texts, one JSON record per line
  • stats.json, summary counts
